# FourthWave

The FourthWave company website, being rebuilt from scratch on this branch
(`redesign`).

The first version of the site, with all of its code, is on `main`.

What is kept here for the new build:

- [docs/CONTENT.md](docs/CONTENT.md) — every text from the first version, with placeholders and demo content marked.
- [docs/PROJECT.md](docs/PROJECT.md) — project goals and structure.
- [docs/DESIGN.md](docs/DESIGN.md) — the first version's design system, for reference.
- `public/` — the photographs, screenshots and video preview.
